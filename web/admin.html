How to run a tournament

  1. Import & Validate — paste your published Google Sheet CSV URL (or a local file / pasted CSV), click Preview, review the validation list, fix any gender/skill inline, then Commit.
  2. Divisions & Brackets — click Build divisions & pairs. Or make a Custom bracket by typing players in. Use Plan on a division to compare formats and time estimates, then approve one. Enter results by clicking a match. Finalize to lock a bracket.
  3. Schedule & Export — Generate schedule (warm-up/buffer/rest built in, no player double-booked), check for conflicts, and export CSVs.
  4. Settings — set courts, day start, slot timing, and match format. These feed the scheduler and planner. No code needed.
  5. Open the Public Display on a second monitor — it mirrors everything live with Overview / Bracket / Standings / Schedule tabs.

Tip: import a file from sample_data/ to practice with fake data first.
